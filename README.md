## XANA-AI-PDT

AI Agent for IndustryFusion Process Digital Twins

### Getting started

XANA runs next to the [IndustryFusion digital twin platform](https://github.com/IndustryFusion/DigitalTwin) and uses its context broker, identity provider, databases and services.

- **Deploy it on a cluster with the platform:** [Quick start in `helm/README.md`](helm/README.md#quick-start), then the rest of that file for every setting.
- **Develop and run it locally:** the backend's [local environment](backend/README.md#local-environment), with Docker Compose and stand-ins for the platform, and the [operator UI](frontend/README.md), which also runs on its own mock data.
- **How it fits together:** [architecture.md](architecture.md).
